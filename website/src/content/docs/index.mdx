A Flask extension for handling Cross Origin Resource Sharing (CORS), making
cross-origin AJAX possible.

This package has a simple philosophy: when you want to enable CORS, you wish to
enable it for all use cases on a domain. This means no mucking around with
different allowed headers, methods, etc.

By default, submission of cookies across domains is disabled due to the security
implications. See [Using CORS with Cookies](/flask-cors/getting-started/#using-cors-with-cookies)
for how to enable credential'ed requests — and please add some sort of
[CSRF](https://en.wikipedia.org/wiki/Cross-site_request_forgery) protection
before doing so!

<CardGrid stagger>
  <Card title="Install" icon="seti:python">
    ```sh
    pip install -U flask-cors
    ```
  </Card>
  <Card title="Enable CORS" icon="approve-check">
    ```python
    from flask import Flask
    from flask_cors import CORS

    app = Flask(__name__)
    CORS(app)
    ```
  </Card>
  <Card title="Extension or decorator" icon="puzzle">
    Apply CORS app-wide with the [`CORS`](/flask-cors/api/extension/) extension,
    or per-view with the [`cross_origin`](/flask-cors/api/decorator/) decorator.
  </Card>
  <Card title="Fully configurable" icon="setting">
    Parameterize every CORS header — origins, methods, headers, credentials,
    max-age and more — globally or per-resource.
  </Card>
</CardGrid>
